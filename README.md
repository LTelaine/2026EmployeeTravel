# 2026 員旅・清邁五日隨身手冊

A 團（10/22 出發、10/26 返台）的行動版行程頁。開 `index.html` 即可，沒有建置流程。

## 內容

- 出發資訊：集合時間地點、去回程航班
- 每日時間軸：飯店 → 景點 → 用餐串成一條線，景點可點開地圖面板
- 景點照片：手冊內頁照片加自行補充的參考照片
- 路線地圖：點「看第 N 天整日路線」開燈箱，OpenStreetMap 街道底圖加路線疊層
- 住宿：兩間飯店的英文地址與電話，可一鍵複製給司機看
- 地區速查、實用數字（時差／電壓／匯率／入境現金／TDAC／小費行情）
- 寺廟服裝提醒、不參加按摩的替代方案

## 檔案

```
index.html   整個頁面（CSS 與 JS 都內嵌，無外部相依）
img/         景點照片與五張路線底圖
```

## 說明

- 這是**個人整理的非官方頁面**，不代表雄獅旅遊或任何單位。
- 時間軸的先後順序依手冊行程推排，用餐位置為推估；**實際時間與順序以現場導遊為準**。
- 路線圖上的藍線是按行程順序的直線，**不是實際行車路徑**。
